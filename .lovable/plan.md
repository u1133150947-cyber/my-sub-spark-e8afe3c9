## Зачем

Сейчас вкладка «➕ Новый» показывает все 25–50 инбаундов каждой панели отдельными чекбоксами. После включения Автовыбора пользователю **не нужно выбирать поштучно** — клиент сам пингует и переключается. Список инбаундов превратился в визуальный шум, в котором легко промахнуться (забыть галку → 1 сервер «выпадет» из Автовыбора).

## Что меняем (только UI вкладки «Новый», бэкенд не трогаем)

### 1. Каждая панель = одна большая карточка-«группа»

Вместо столбца чекбоксов — **одна строка с переключателем «Подключить все»** и сводкой:

```text
┌─────────────────────────────────────────────────────────┐
│  🇨🇿 Чехия                                 [✓ Подключить] │
│  25 серверов · VLESS Reality · ⚡ Автовыбор активен      │
│  SNI: microsoft, apple, cloudflare, github + 6          │
│                                          ▾ Настроить    │
└─────────────────────────────────────────────────────────┘
```

При клике «Подключить» в `selected` Set добавляются **сразу все** ключи `panel:inbound_id` этой панели. Логика создания подписки и раскладка по `subscription_inbounds` не меняются.

### 2. «Настроить» = раскрывающийся продвинутый режим

Под карточкой раскрывается тот же текущий список чекбоксов с возможностью:
- снять отдельные инбаунды (если, например, не хочешь VMess в группе);
- переименовать, добавить всем, убрать у всех (как сейчас);
- видна тонкая полоска «выбрано N из M».

По умолчанию свёрнут. Состояние раскрытия — локально в `useState<Record<panel, boolean>>`.

### 3. Сводка серверов считается автоматически

Из `inbounds[panel]` собираем:
- **count** — сколько всего;
- **protocols** — уникальные `ib.protocol` (VLESS / HY2 / Trojan / VMess / SS);
- **sni** — топ-5 уникальных `serverName` из `stream_settings.realitySettings`/`tlsSettings` для подсказки качества пула.

Это чисто рендеринг, никаких новых запросов.

### 4. Бейдж «Автовыбор активен»

Зелёная пилюля рядом с заголовком панели появляется когда `count >= 2` — намёк, что подписка получит работающий ⚡ Автовыбор в sing-box формате.

### 5. Кнопка «Сбросить к Авто» в развёрнутом режиме

Если пользователь поковырялся вручную — одной кнопкой возвращает «выбрать все из этой панели» обратно.

### 6. Поведение по умолчанию для новых подписок

При первой загрузке формы все панели **уже подключены** (галка ON), как и раньше для удобства. Меняется только подача — групповая, а не поштучная.

## Что НЕ меняем

- `subscription_inbounds` структура;
- логика `create()` (всё так же шлёт по client per inbound на 3x-ui);
- edge-функция `sub` и форматы (`default` / `singbox` / `xray`);
- вкладки «Подписки», «Панели», «Сторонние» и т.д.

## Технические детали

Файл: `src/pages/Index.tsx`, секция `<TabsContent value="create">` ~ строки 1245–1380.

Новый компонент-помощник внутри файла (или вынести в `src/components/InboundPanelGroup.tsx`):

```tsx
type Props = {
  panel: PanelMeta;
  list: InboundInfo[];
  selected: Set<string>;
  onToggleAll: (on: boolean) => void;
  onToggleOne: (key: string) => void;
  // + рендер DropdownMenu для каждого инбаунда (как сейчас)
};
```

Хранение раскрытия:

```tsx
const [expanded, setExpanded] = useState<Record<string, boolean>>({});
```

Расчёт сводки — мемо:

```tsx
const summary = useMemo(() => list.reduce(...), [list]);
```

Селект «всех в панели» — два батча:

```tsx
const allKeys = list.map((i) => `${panel.slug}:${i.id}`);
const allOn   = allKeys.every((k) => selected.has(k));
const noneOn  = allKeys.every((k) => !selected.has(k));
// indeterminate = !allOn && !noneOn
```

Toggle:

```tsx
setSelected((prev) => {
  const next = new Set(prev);
  if (allOn) allKeys.forEach((k) => next.delete(k));
  else       allKeys.forEach((k) => next.add(k));
  return next;
});
```

## Бонус (если ок)

Сверху над списком панелей добавить **глобальный переключатель** «Все панели · Авто» — один клик подключает все 50+ инбаундов со всех серверов, для VIP-тарифа.

## Что НЕ делаем без отдельного запроса

- Не трогаем «Сторонние подписки» — там логика другая.
- Не вводим серверный концепт «авто-группа» в БД — это чистая UX-агрегация, инбаунды по-прежнему хранятся раздельно.
- Не убираем продвинутый режим — он нужен для редких случаев (тестовый сервер, временно отключить один SNI).
